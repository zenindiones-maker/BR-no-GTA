Normative language

Definition of Working

Um teste verde não é “sistema funcionando”.

MUST / MUST NOT

MUST = requisito obrigatório. MUST NOT = proibido. Violação é FAIL. SHOULD exige justificativa quando não seguido. MAY é opcional.

SYSTEM_OPERATIONAL=PASS

  • G0–G14 todos PASS.
  • Evidence fresh e ligada ao HEAD/mission/task correto.
  • Nenhum successor contraditório ativo/queued.
  • Zero authority escape, secret leak, artifact mismatch e unintended publication.
  • Produto final respeita voz, duração, QA e review.
Proibido: UNKNOWN/UNPROVEN→PASS, CI GREEN→produto entregue, ou agent self-report→evidência canônica.

Provider resilience

Recovery causal

503/timeout/quota são eventos operacionais tipados.

Capture

provider/model/status/retryable/stage/latency.

Classify

model-local, provider-wide, quota/rate-limit, transient, auth, contract.

Circuit/admission

CLOSED/OPEN/HALF-OPEN + fresh health.

Recover

bounded retry, alternate eligible route, WAIT, REPLAN ou AUTH_REQUIRED.

Persist

FailureEpisode + deterministic backoff/wake + idempotent requeue.

Provider não é autoridade. Blind retry e immediate terminal failure são ambos incorretos quando a failure class não os autoriza.
