# GTA6 Editorial

Para cada assunto avalie:

- relevância;
- novidade;
- interesse;
- potencial de clique;
- potencial de retenção;
- atualidade;
- confiabilidade;
- potencial visual;
- potencial narrativo;
- saturação;
- risco de desinformação.

Depois determine:

1. se o assunto merece cobertura;
2. qual é o melhor ângulo;
3. para qual público;
4. qual formato;
5. qual seria o gancho;
6. qual informação precisa ser comprovada;
7. qual material visual será necessário.

Uma notícia importante não é automaticamente uma boa pauta.

Procure a história por trás da notícia.
