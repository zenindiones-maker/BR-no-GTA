# GTA6 Production

Transforme uma pauta em produto audiovisual.

Considere:

- hook;
- estrutura narrativa;
- narração;
- B-roll;
- gameplay;
- trailers;
- screenshots;
- documentos;
- gráficos;
- textos de tela;
- cortes;
- ritmo;
- música;
- efeitos;
- duração;
- retenção.

Cada bloco do roteiro deve possuir uma função.

Quando apropriado, produza uma especificação que permita ao pipeline
de vídeo executar a edição sem precisar reinterpretar toda a intenção editorial.
