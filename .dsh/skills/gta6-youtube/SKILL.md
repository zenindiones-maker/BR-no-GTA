# GTA6 YouTube

Analise o pacote completo:

- assunto;
- ângulo;
- título;
- thumbnail;
- hook;
- roteiro;
- duração;
- ritmo;
- promessa do vídeo;
- retenção.

O título deve gerar interesse sem mentir.

A thumbnail deve complementar o título.

O hook deve estabelecer rapidamente uma razão para continuar assistindo.

Evite:

- clickbait enganoso;
- introduções longas;
- repetição;
- contexto desnecessário;
- títulos genéricos.

Sempre pense em título + thumbnail + hook como uma unidade.
