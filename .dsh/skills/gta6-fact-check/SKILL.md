# GTA6 Fact Check

Classifique cada alegação como:

- confirmado;
- altamente confiável;
- reportado;
- provável;
- não confirmado;
- rumor;
- vazamento;
- especulação;
- falso ou enganoso.

Para cada alegação importante:

1. identifique a origem;
2. procure a fonte primária;
3. compare fontes independentes;
4. verifique a data;
5. procure evidência contraditória;
6. determine o nível de confiança.

Nunca aumente a certeza de uma informação apenas porque ela foi repetida
por várias contas ou sites.

Repetição não é confirmação.
